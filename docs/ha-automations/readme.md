# Home Assistant automations

This directory is a collection of Home Assistant automations for TECHO5 devices.

These examples show some of the things we have put together with TECHO5. They are here to
share ideas, useful patterns, and working setups that may be helpful in another home.

## A note of thanks

My contribution to TECHO5 is limited to this collection of Home Assistant automation examples.
The work behind the project belongs to HuskerMinion and everyone who has contributed to TECHO5.
All appreciation goes to them.

## Browse the examples

The collection will keep growing, and each setup is a little different. Feel free to use an
example as it is, adapt it to your own devices, or simply use it as a starting point.

## Share an automation

If you have an automation you would like to share, you are welcome to add it here. New
approaches to a familiar task are useful too: seeing how someone else has solved something
can make it easier for the next person to find an approach that fits their setup.

There is no required format beyond keeping the example understandable and including any
important assumptions about the entities or helpers it uses. Thank you for helping us share
what has been accomplished with TECHO5, and what is yet to come.
